One line of patch notes announcing that human sleep has been fixed. The program writes one line to `/output/entry.txt`:

> Fixed: the brain no longer opens all 47 unfinished thoughts the moment your head touches the pillow.

## Why this line

Judged, most important first, on whether it really reads as a patch note about fixing human sleep, whether the joke lands on a single read, whether it sounds like genuine release notes, whether it stays a single line under the cap, and whether the fix is specific and surprising:

- **Patch note:** opens with "Fixed:" and names the fix — sleep — in the first breath, not a joke about something else.
- **Lands on one read:** the brain opening all 47 unfinished thoughts the second your head touches the pillow — every tab of the day reopening at once, right when you need them closed.
- **Changelog voice:** terse, confident, no explaining the joke — "no longer opens", a shipped fix, not a promise.
- **Single line:** 100 characters, no padding, no trailing explanation.
- **Specific surprise:** not "sleep is now fixed" but *which* bug was fixed — the 3 a.m. replay of everything unfinished — with a number (47) that makes it concrete.

## Run it

```sh
python3 main.py
```
